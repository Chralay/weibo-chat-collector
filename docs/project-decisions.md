# 项目决策记录

## 已确认

- 当前按两个微博账号、两个微博群聊规划。
- 两个微博号的数据放入同一个数据库。
- 每条消息必须保留账号和群聊来源。
- 采集范围是群聊中所有用户的消息。
- 红包类消息不保存。
- 首次测试采集范围：最近 7 天。
- 图片和文件需要下载原件。
- 批量删除默认采用软删除。
- 手动上下文补充表单取消。
- 上下文查看、统计仪表盘、导出备份后移。

## 暂用占位

你已确认账号和群聊映射，但当前没有在对话里提供具体名称。开发阶段先使用以下占位：

- 微博账号 A：`account_a`
- 微博账号 B：`account_b`
- 账号 A 对应群聊：`group_a`
- 账号 B 对应群聊：`group_b`

后续可以在配置文件或管理界面中替换成真实名称。
